- **任务书两处前提是错的**：① **本项目没有 theme context**——主题是 `App.tsx` 把 5 个 token 当 **inline style 的 CSS 变量**挂在根 div 上，页面用 `var()` 取值。所以「跟随主题」= 换变量，不需要 context、不需要读 DOM（读 DOM 会读到旧值，切换慢一拍）。② 任务书给的深色色值（`#1e1e1e`/`#e0e0e0`/`#3c3c3c`）与项目 token（`#0f172a`/`#f1f5f9`/`#334155`）**完全不同**，照抄会和已适配页面割裂。
- **`#fff` 有两种语义，必须逐处判断**：卡片底色 → `var(--surface)`；彩色按钮上的白字 → **保留 `#fff`**（换成变量会让深色下按钮文字变深色，直接看不见）。全局替换会翻车。
- **语义色用「半透明底 + 500 档文字」是唯一不需要判主题的解**：`#fee2e2` 这类浅底在深色页上是刺眼亮斑；`rgba()` 叠浅底是淡色、叠深底是暗色，一个值适配两档。文字必须提亮（深红 `#b91c1c` 在暗底上对比度仅 1.6:1）。
- **红按钮 `#dc2626`→`#b91c1c`**：降亮度同时白字对比度 5.9→6.5，一次改动满足两个目标。
- **顺带修两个既有缺陷**：① disabled 按钮「半透明底+白字」，白字几乎看不见（浅色下更糟）→ `var(--text-muted)`；② Items 行 hover 第一版用 `var(--bg)` **完全看不出**（表格透明，行背景=页面背景，`--bg` 同色）→ 改 `var(--surface)`。**这两个都是截图看出来的，不是想出来的。**
- **★ 本机 WebView2 能跑了！** 之前 MEMORY 记「渲染进程创建即崩」，这次实测：**MSI 装到干净目录 → 带 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` 启动 → 进程存活、Responding=True、19 个 webview2 子进程、CDP 200**，能连 `http://tauri.localhost/` 截真实应用页面图（含真实数据库数据）。**这是以后拿安装态 GUI 证据的正确姿势，比 headless Edge 模拟强得多。**
  - 关键：必须用 `Start-Process`（不是 `&`）+ 后台会话里 `Start-Sleep` 保持，否则进程随会话被清理；启动前先 `Stop-Process` 清残留 webview2，否则单实例锁会让新实例立刻退出。
- **Edge headless 的坑**：相对路径按**进程工作目录**解析，`--screenshot=target/x.png` 报「系统找不到指定的路径」，**必须绝对路径**（`--user-data-dir` 同理）。
- **React 的 `onMouseEnter` 是 `mouseover` 代理的**，`dispatchEvent(new MouseEvent("mouseenter"))` 不触发合成事件，要用 `mouseover` + `bubbles:true`。
