### 关键经验（可复用）
1. **动态 WHERE 必须让分页、COUNT、SUM 共用同一份 where_clause 与参数**，否则筛选后 `total` 会漂移，前端分页栏直接错。
2. **Tauri 2 参数名自动 camelCase→snake_case**：`safe_box_list` 的 `pageSize`→`page_size`、`sessionIds`→`session_ids`、`fromTs`→`from_ts`；`Option<T>` 缺省即 `None`，前端不传即可，不必显式 `null`。
3. **本机 `git push` 会因全局 `http.sslbackend=openssl` 报 `TLS connect error: error:0A000126 ... unexpected eof`**，用 `git -c http.sslBackend=schannel push` 可绕过（未改全局配置）。后续 push 直接带这个 `-c`。
4. **NSIS `perMachine` 在非管理员 shell 无法静默安装**（会弹 UAC / 残留 `consent.exe`）；要验证安装级布局改用 **MSI per-user**：`msiexec /i xxx.msi /qn ALLUSERS=2 MSIINSTALLPERUSER=1 INSTALLDIR=<dir>`。
5. **GitHub API 经代理必须带 `User-Agent`**，否则被拒；本机 `curl --noproxy '*'` 对 `api.github.com` 直接不通，需走 `http://127.0.0.1:8607`。
6. GUI 取证连续第三轮被 WebView2 渲染进程崩溃阻断（Crashpad 新增 `.dmp`、CDP 9222 `10061` 拒绝），**按第三档登记 + jsdom/引擎集成用例补偿，不伪造证据**。
