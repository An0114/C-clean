## 任务目标

### Bug-1（P0）：WinSxS 「分析组件存储」DISM 退出码 3

- **现象**：点 WinSxS「分析」按钮直接红字「分析失败：DISM 分析失败（退出码 3）：」。
- **排查方向**：
  - 是提权通道（`cclean-elevation.exe`）没正确拉起 DISM；
  - 还是命令参数不对；
  - 还是本机 DISM 组件本身报错。
- **修法**：
  - 先复现并定位根因；
  - 若提权通道问题：修 `elevation/src/main.rs` 命令白名单参数传递；
  - 若 DISM 参数问题：修 `engine/src/scan/winsxs.rs` 命令拼接；
  - 若本机环境问题：加错误码解读 + 用户提示。

### Bug-2（P1）：普通清理扫描结果只有 L1，L2/L0 缺失

- **现象**：扫描后清理页风险列全是 L1（windows_update / temp / browser_cache / prefetch），无 L0/L2；L3 属红线本就不进列表（预期）。
- **排查方向**：
  - 5 个 `.ps1` 扫描脚本是否把所有项硬编码成 L1；
  - 或 L2 规则在这些模块里本就不命中。
- **修法**：
  - 先复现并定位根因；
  - 若 ps1 硬编码 L1：修 `scripts/` 下 5 个扫描脚本，正确输出风险等级；
  - 若规则不命中：修 `rules/cache_rules.json` 规则库，补 L2 规则。

### Bug-3（P1）：残留项入保险箱后「永久删除」报内部错误 + 来源列无来源

- **现象**：残留页移入的 `C:\Program Files\HONOR`（65.1 MB）在保险箱页批量删除时报「Error: 内部错误（附日志 ID）」；同时残留来源项来源列显示「历史（无来源）」，而扫描清理来的项正确显示 `#1`。
- **排查方向**：
  - 永久删除路径对残留入箱的大目录是否有权限/路径处理问题；
  - 残留移入保险箱是否走了非 cleanup_execute 路径导致 source_task_id 恒 NULL。
- **修法**：
  - 先复现并定位根因；
  - 若永久删除路径问题：修 `engine/src/execute/safe_box.rs` 目录递归删除逻辑；
  - 若 source_task_id 问题：修 `engine/src/ipc/commands/residual.rs` 残留移入保险箱时写入 source_task_id。

**本任务不做**：
- 不做原计划 P1-7 清理方案模板（延后到 task-071）；
- 不做跨盘恢复 fallback / RmShutdown 三功能（维持现状）。
