## 1. 项目简介

**C-Disk Cleaner** 是一款面向普通用户与开发者的 Windows C 盘安全清理桌面应用。

**一句话定位**：先扫描诊断、按风险分级、用户自主选择、执行可追溯——把「会清理」变成「敢清理、看得见、能回滚」。

**差异化**：
- 对大众用户：像 CCleaner 一样一键上手，但默认更保守（可回滚、不碰注册表批量清理、无全家桶推广）。
- 对专业用户/开发者：像 Dism++ 一样提供深度能力，但每步有解释、有影响说明。
- 核心主张：**每一个删除决定都有依据，每一次清理都能追溯。**

**产品形态**：Windows 10/11 原生桌面应用（x64 / ARM64），可常驻系统托盘。完全不支持 macOS / Linux。

**开源策略**：全项目开源（MIT），所有功能免费，无 Pro 版本、无广告、无遥测。

## 2. 用户画像 & 业务目标

### 2.1 用户画像

| 用户类型 | 典型特征 | 核心痛点 | 核心诉求 |
|----------|----------|----------|----------|
| **普通用户（小白）** | C 盘红了才想起清理，不懂系统结构，怕删坏 | 不敢乱删、怕删错、看不懂专业术语 | 一键安全清理，操作简单，出了问题能恢复 |
| **开发者** | AppData 膨胀，微信/IDE/包管理器缓存几十 GB | 缓存目录多、分散，手动清理耗时 | 自动识别各类开发工具缓存（npm/pip/Maven/Gradle/Rust 等），精准高效 |
| **IT 运维 / 装机人员** | 需要批量处理多台机器，或给客户装机后清理 | 重复操作多，需要标准化流程 | 便携版、命令行版、清理方案模板复用 |

### 2.2 业务目标

| 目标维度 | 具体指标 |
|----------|----------|
| **用户价值** | 普通用户完成一次 C 盘清理平均释放空间 ≥ 5GB；误删率 = 0（L3 红线拦截） |
| **信任建立** | 保险箱默认开启，7 天内可恢复；每次清理有审计日志可追溯 |
| **产品定位** | 差异化于"全家桶式清理工具"和"纯专业工具"，占领"安全 + 可解释"心智 |
| **社区增长** | 开源后规则库共建活跃，GitHub Issues / PR 持续流入 |

## 3. 范围定义（包含/不包含）

### 3.1 V1.0 包含范围

| 模块 | 说明 |
|------|------|
| 六大清理维度 | 应用缓存、系统临时与日志、系统组件存储（WinSxS）、已卸载残留、系统级大文件、注册表健康 |
| 风险分级体系 | L0 只读 / L1 安全 / L2 需确认 / L3 禁止，四级可视化徽标 |
| 清理闭环 | 扫描 → 分级展示 → 用户勾选 → DryRun 预演 → 确认执行 → 结果报告 → 历史归档 |
| 清理保险箱 | 默认开启，延迟删除，7 天内可恢复 |
| 占用进程感知 | 检测目标路径被哪些进程占用，用户确认后关闭 |
| 清理报告 | 前后空间对比、成功/失败明细、释放总量，可导出 |
| L3 红线硬拦截 | 禁止项不出现在可勾选列表，代码层二次校验 |
| 启动仪表盘 | C 盘用量总览、可释放空间预估、上次清理收益 |
| 系统托盘常驻 | 快速入口（立即扫描 / 查看结果 / 打开保险箱 / 退出） |

### 3.2 不包含范围（V1.0 明确不做）

| 不做项 | 原因 |
|--------|------|
| macOS / Linux 支持 | 深度依赖 Windows DISM、注册表、WMI，跨平台不划算（立项决策 #6） |
| 付费 / Pro 版本 | 全部功能免费开源，信任优先 |
| 广告 / 推广 / 全家桶捆绑 | 产品定位即"反全家桶" |
| 遥测 / 数据上传 | 隐私承诺，全本地处理 |
| 远程协助 / 云清理 | 无服务端架构 |
| 磁盘碎片整理 | 不属于"安全清理"范畴，且现代 SSD 无需碎片整理 |
| 病毒查杀 / 防火墙 | 明确不做安全软件，只做清理 |
| 移动端 / 网页版 | 桌面系统工具，无此场景 |

## 4. 功能需求（按 P0/P1/P2 分级）

> 优先级定义：
> - **P0**：必须 MVP 上线，没有就不叫产品（M1 Alpha 核心闭环）
> - **P1**：一期迭代，显著提升体验与专业度（M2 Beta + M4 1.1）
> - **P2**：二期/长期增强，锦上添花（M5 社区化长期）

### P0-1 一键智能扫描

**用户故事**：作为用户，我点击"立即扫描"后应用自动扫描 C 盘六大维度的可清理项，不需要我手动选择扫描哪些目录，扫描过程中界面不卡顿。

**验收标准**：
1. 点击"立即扫描"后，应用开始全量扫描（应用缓存 + 系统临时 + WinSxS 分析 + 残留 + 大文件 + 注册表），总耗时 ≤ 3 分钟（普通办公电脑）。
2. 扫描过程中显示实时进度条与当前正在扫描的目录名，UI 响应流畅（不卡顿、不白屏）。
3. 扫描为**只读操作**，全程不修改任何文件。
4. 扫描完成后自动跳转到结果页，按模块分组展示。
5. 扫描中用户可以切换到其他页面（如历史、保险箱），不影响后台扫描。
6. 支持"取消扫描"按钮，点击后立即停止并保留已扫描到的结果。

---

### P0-2 分级结果展示

**用户故事**：作为用户，我希望扫描结果按风险等级和模块分组展示，每项能看到路径、大小、说明、风险徽标和"删了会怎样"的解释，而不是一堆看不懂的路径列表。

**验收标准**：
1. 结果页按六大模块分组（应用缓存 / 系统临时与日志 / 组件存储 / 已卸载残留 / 系统级大文件 / 注册表健康），每个模块显示小计大小与可勾选数量。
2. 每项清理项显示：文件路径、占用大小、风险等级徽标（L1 绿色 / L2 黄色 / L0 灰色）、功能说明、影响与重建方式（如"删除后微信会重新下载图片缩略图"）。
3. L3 禁止项**不出现在可勾选列表中**，用户无法通过任何操作勾选到 L3 项。
4. 默认按大小降序排列，支持按模块筛选、按风险等级筛选。
5. 每项默认折叠，展开后显示完整说明与影响；L2 项展开后额外显示回滚方式说明。
6. 顶部实时显示"已勾选 X 项，预计释放 Y GB"。

---

### P0-3 L1 安全清理一键执行

**用户故事**：作为普通用户，我希望绿色标注的安全项可以一键全选并清理，不需要我逐项确认，因为这些都是"删了也会自动重建"的缓存。

**验收标准**：
1. 提供"全选 L1 安全项"按钮，一键勾选所有 L1 级别的清理项。
2. L1 项默认已勾选（或一键全选后），用户点击"执行清理"前必须经过 DryRun 预演确认。
3. 清理前弹出预演确认框，显示：将删除的文件总数、预计释放空间、涉及模块数量。
4. L1 项的清理执行后，对应目录内的缓存文件被移除，但应用本身及其配置、用户数据不受影响。
5. 清理完成后显示结果报告：成功项数、失败项数、实际释放空间。
6. L2 项**默认不勾选**，勾选时需弹出二次确认说明影响。

---

### P0-4 清理保险箱（差异化核心）

**用户故事**：作为用户，我怕删错东西，所以希望被清理的文件不是直接删除，而是先放到一个"回收站"一样的保险箱里，我后悔了还能恢复。

**验收标准**：
1. 所有清理操作**默认启用保险箱**：被删文件先移入应用保险箱目录，而非直接永久删除。
2. 保险箱容量上限默认 5 GB；写满时自动淘汰最旧文件（按移入时间先进先出），淘汰前记录日志。
3. 保险箱内文件保留 7 天，到期后自动永久清除并记录审计日志。
4. 保险箱页面展示：文件列表（原路径、大小、移入时间、剩余保留天数）、大小统计、清空按钮。
5. 支持单文件"恢复"操作：恢复后文件回到原始路径（如原始路径已不存在则提示）。
6. 支持"全部恢复"和"全部永久删除"操作。
7. 用户可在设置中关闭保险箱（关闭后直接永久删除），但关闭时需弹出醒目警告确认。
8. V1 保险箱仅位于 C 盘本地路径，不支持迁移到其他盘。

### P0-5 占用进程感知

**用户故事**：作为用户，我清理的时候如果某个文件正被微信或浏览器占用，应用能告诉我是哪个程序占用了，并问我要不要关掉它再清理。

**验收标准**：
1. 扫描阶段自动检测各清理项是否被运行中的进程占用。
2. 被占用的清理项标记"占用中"状态，并显示占用进程名称。
3. 执行清理前，如果有选中项被占用，弹出提示："以下 N 项被 XX 等进程占用，是否关闭后继续清理？"
4. 用户确认关闭后，应用自动关闭对应进程，再继续执行清理。
5. 用户选择"跳过被占用项"时，未占用项正常清理，被占用项标记为"已跳过"。
6. 关键系统进程（如 explorer.exe、svchost.exe 等）不提供"关闭"选项，仅提示"无法关闭，请手动关闭后重试"。

---

### P0-6 清理报告

**用户故事**：作为用户，我想知道清理完之后到底释放了多少空间、哪些成功了哪些失败了，最好能导出报告留档。

**验收标准**：
1. 每次清理完成后自动生成报告页，包含：
   - 清理前 / 清理后 C 盘剩余空间对比；
   - 实际释放总空间；
   - 成功清理项数 / 失败项数 / 跳过项数；
   - 按模块分组的明细列表。
2. 失败项显示具体失败原因（如"文件被占用"、"权限不足"）。
3. 支持导出报告为 HTML 文件和 CSV 文件，用户自选保存位置。
4. 报告数据自动写入历史库，可在"历史与趋势"页面回看。

---

### P0-7 L3 红线硬拦截

**用户故事**：作为用户，我信任这个工具不会删我的个人文件和系统关键文件，因为它从设计上就不可能碰到这些。

**验收标准**：
1. 以下路径/类别永远不会出现在可勾选清理列表中：
   - 用户个人目录：桌面、文档、下载、图片、视频、音乐；
   - 浏览器个人数据：书签、密码、历史记录、User Data 主目录；
   - 系统关键路径：pagefile.sys、swapfile.sys、System32、Windows\Installer；
   - WinSxS 的 /ResetBase 操作（UI 层不存在该选项）。
2. 即使通过外部方式篡改 UI，执行引擎内部仍有路径白名单二次校验，不在白名单内的路径一律拒绝删除。
3. 注册表清理默认只删明确无效项，不做批量注册表清理；删除前强制导出 .reg 备份。
4. 还原点默认保留最新一个，不允许批量删除所有还原点。

---

### P0-8 启动仪表盘（空间总览）

**用户故事**：作为用户，我打开应用第一眼就能看到 C 盘现在用了多少、还剩多少、大概能清理出多少空间，不用点进去才知道。

**验收标准**：
1. 应用启动后默认展示仪表盘首页，包含：
   - C 盘总容量 / 已用空间 / 剩余空间（环形图或进度条可视化）；
   - 上次扫描的"预估可释放空间"（如有历史记录）；
   - 上次清理的实际释放收益（如有历史记录）；
   - 醒目的"立即扫描"主按钮。
2. 仪表盘数据实时反映当前磁盘状态。
3. 首次使用（无历史记录）时，引导文案提示"点击立即扫描开始"。

---

### P0-9 系统托盘常驻

**用户故事**：作为用户，我希望这个工具不用一直开着窗口，缩到托盘里就行，想扫的时候右键点一下就好。

**验收标准**：
1. 关闭主窗口时，应用最小化到系统托盘而非退出。
2. 托盘图标右键菜单包含：打开主界面、立即扫描、查看上次结果、打开保险箱、退出。
3. 双击托盘图标打开主界面。
4. 退出托盘菜单时需确认（防止误点退出）。

---

### P0-10 清理前自动创建还原点

**用户故事**：作为用户，我清理系统类项目之前希望能自动创建一个系统还原点，万一出问题可以恢复系统。

**验收标准**：
1. 设置中有"清理前自动创建系统还原点"开关，**默认开启**。
2. 当本次清理包含 L2 或以上风险项、或包含注册表 / WinSxS 操作时，执行前自动创建还原点。
3. 还原点创建成功后，在执行确认框中提示"已创建系统还原点：XXX"。
4. 还原点创建失败时（如系统未开启还原功能），弹出提示告知用户，并询问是否继续。
5. 用户可在设置中关闭此开关（关闭后需确认警告）。

### P1-1 计划自动清理

**用户故事**：作为用户，我希望这个工具能每周自动帮我扫一次，只清理安全项，不用我每次手动操作。

**验收标准**：
1. 设置中可配置计划任务：频率（每周/每两周/每月）、执行时间。
2. 可配置自动清理规则：
   - 只清理 L1 安全项（L2 及以上仅扫描不自动清理）；
   - 仅当预估释放空间 ≥ 用户设定阈值（如 5GB）时才自动执行。
3. 计划任务执行完成后，在托盘弹出通知告知结果。
4. 用户可随时暂停 / 恢复计划任务。

---

### P1-2 大文件 / 重复文件地图

**用户故事**：作为用户，我想知道 C 盘里到底哪些大文件占了空间，哪些文件夹最占地方，而不只是缓存。

**验收标准**：
1. 提供"大文件地图"页面，展示 C 盘 Top 100 大文件（按大小排序），包含文件路径、大小、类型。
2. 支持按文件夹层级展示占用分布（类似矩形树图或文件夹大小排行）。
3. 大文件仅做展示和"定位到文件夹"操作，**不提供直接删除选项**（避免误删个人文件）。
4. 重复文件检测：识别内容相同的重复文件，按组展示，用户自行决定保留哪份。
5. 大文件地图扫描结果标记风险等级，用户个人目录中的大文件标记为"只读参考"。

---

### P1-3 残留一键定位

**用户故事**：作为用户，我发现某个软件卸载了但它的文件夹还在，我想知道这个残留到底是哪个软件留下的、什么时候卸载的。

**验收标准**：
1. 已卸载残留模块中，每个残留目录自动关联到注册表卸载记录，显示对应软件名称和卸载时间。
2. 残留项标记风险等级：仅空文件夹 / 缓存残留 = L1；含配置文件残留 = L2。
3. 提供"打开所在文件夹"按钮，一键定位到残留目录。
4. 用户确认后可清理残留目录，清理前仍走保险箱流程。

---

### P1-4 注册表健康中心

**用户故事**：作为用户，我想清理无效的注册表启动项和残留键，但要每一项都能确认、能备份、能恢复。

**验收标准**：
1. 注册表模块扫描范围：无效启动项（Run 键）、已卸载软件残留键、无效计划任务。
2. 每个注册表项显示：键路径、值名称、指向的文件路径、无效原因（如"指向文件不存在"）。
3. **删除前强制导出 .reg 备份文件**，备份路径用户可见可查。
4. 注册表清理默认逐项确认（不提供"全选批量删除"）。
5. 支持查看清理历史中的注册表操作记录，随时导出当时的备份 .reg 文件。

---

### P1-5 清理历史与趋势

**用户故事**：作为用户，我想知道我的 C 盘空间是怎么变化的、每次清理都赚了多少空间，有没有规律。

**验收标准**：
1. 历史页面展示历次清理记录：日期、释放空间、清理项数、耗时。
2. 提供 C 盘剩余空间趋势图（折线图），横轴为时间，纵轴为剩余空间。
3. 提供累计清理收益统计（总释放空间、清理次数）。
4. 支持按时间范围筛选历史记录。
5. 点击单次历史记录可查看该次清理的详细报告。

---

### P1-6 规则库热更新

**用户故事**：作为用户，我希望这个工具能自动认识新出的软件缓存，不用等整个软件升级。

**验收标准**：
1. 应用内置缓存规则库版本号，设置中显示当前规则库版本。
2. 提供"检查规则更新"按钮，点击后从云端拉取最新规则 JSON。
3. 拉取后本地校验 checksum（SHA-256），一致则替换本地规则库。
4. 规则库更新后，下次扫描自动生效。
5. 唯一网络请求为规则库 JSON 更新和版本检查，设置中可完全关闭自动更新。
6. **安全边界**：规则库仅为 JSON 数据（关键词、路径、分级），永远不包含可执行代码。

### P1-7 清理方案模板

**用户故事**：作为运维人员，我希望把常用的清理勾选组合存成模板，到不同机器上一键套用。

**验收标准**：
1. 用户可将当前勾选的清理项组合保存为"方案模板"，命名 + 备注。
2. 方案模板列表页展示已保存的模板，支持一键应用（自动勾选对应项）。
3. 支持导出模板为 JSON 文件，支持导入 JSON 模板。
4. 模板按创建时间排序，支持重命名和删除。

### P1-8 目标空间模式

**用户故事**：作为用户，我不想一项项选，我只想说"我要腾出 20GB"，工具帮我推荐怎么组合最安全。

**验收标准**：
1. 仪表盘或结果页提供"目标空闲空间"输入框。
2. 用户输入目标值后，应用自动推荐组合方案（优先 L1，其次安全的 L2），标注预计达成度。
3. 推荐方案默认勾选，用户可微调。
4. 若按安全项无法达到目标，明确提示"仅安全项最多可释放 X GB，距目标还差 Y GB，需纳入以下 L2 项"。

### P2-1 多用户 / 多盘扫描

**用户故事**：作为用户，我这台电脑有多个用户账号，或者 C 盘不够我还想看看 D 盘哪些可以清理。

**验收标准**：
1. 支持扫描其他用户 Profile 目录（需管理员权限），结果标记"其他用户"。
2. 支持扫描其他磁盘（D/E 盘等），但默认**只读报告模式**，不提供直接清理（防止误删个人文件）。
3. 多盘清理需用户明确切换到目标盘后，再单独执行清理流程。

### P2-2 用户自定义缓存规则

**用户故事**：作为高级用户，我知道某些目录是缓存但默认规则没覆盖，我想自己加进去。

**验收标准**：
1. 设置中提供"自定义规则"入口，用户可添加自定义缓存目录路径。
2. 自定义规则标记"自定义"徽标，与内置规则区分。
3. 添加自定义规则时需用户确认"我确认该目录可安全清理"。
4. 自定义规则支持启用/禁用切换和删除。

### P2-3 深色 / 浅色主题切换

**用户故事**：作为用户，我希望应用能跟着系统主题走，或者我自己选深色模式。

**验收标准**：
1. 设置中提供主题选项：跟随系统 / 浅色 / 深色。
2. 切换主题后全局即时生效，无需重启。
3. 高分屏（4K / 缩放 150%+）下字体和图标清晰适配。

### P2-4 便携版与 CLI 版

**用户故事**：作为运维人员，我不想在每台客户电脑上都安装一遍，我想拷个 U 盘就能用。

**验收标准**：
1. 提供便携版（绿色免安装），解压即可运行，配置数据存于程序同目录。
2. 提供命令行（CLI）版本，支持参数化调用扫描和清理，输出 JSON 结果，可被脚本集成。
3. CLI 版完整继承 DryRun、白名单校验、保险箱等安全机制。

## 5. 业务规则

### 5.1 风险分级规则

| 等级 | 判定标准 | UI 表现 | 交互约束 |
|------|----------|---------|----------|
| L0 只读 | 个人目录、不建议清理的系统目录 | 灰色信息卡 | 无操作按钮，仅展示 |
| L1 安全 | 缓存占比 > 50% 的目录、纯缓存目录、系统临时文件 | 绿色徽标 | 可一键全选，仍需用户点击执行 |
| L2 需确认 | 含用户配置/数据库的缓存、大文件、休眠文件、残留目录 | 黄色徽标 + 影响说明 | 默认不勾选；勾选需展开确认弹窗 |
| L3 禁止 | 系统关键路径、个人文件、浏览器个人数据、WinSxS ResetBase | 不展示 / 红色置灰 | 代码层拦截，无法进入清理清单 |

### 5.2 保险箱业务规则

| 规则项 | 具体内容 |
|--------|----------|
| 默认开启 | 所有清理操作默认经过保险箱，用户可手动关闭 |
| 容量上限 | 5 GB（默认） |
| 淘汰策略 | 写满时自动淘汰最旧文件（按移入时间先进先出） |
| 保留期限 | 7 天，到期自动永久清除 |
| 存放位置 | C 盘本地路径，V1 不支持迁移到其他盘 |
| 恢复规则 | 恢复到原始路径；原始路径已不存在时提示用户选择位置 |

### 5.3 清理执行规则

1. **DryRun 预演必须存在**：任何清理执行前，先生成"将删除清单"展示给用户确认，不允许跳过。
2. **最小权限原则**：扫描永远不需要管理员权限；只有写操作（清理系统目录、注册表、WinSxS）才触发 UAC 提权。
3. **无常驻提权**：提权操作完成后立即退出，不驻留后台。
4. **注册表清理**：默认单条确认，删除前强制导出 .reg 备份。
5. **WinSxS 清理**：仅允许 DISM 安全清理，永远不提供 /ResetBase 选项。
6. **还原点**：清理前自动创建还原点（默认开启），保留最新一个还原点，不批量删除。

### 5.4 隐私规则

1. 全本地处理，无遥测、无云上传、无广告 SDK。
2. 唯一网络请求：规则库 JSON 更新 + 版本检查（可完全关闭）。
3. 扫描数据不上传；报告导出由用户自行决定存放位置。

## 6. 异常场景 & 错误处理

| 异常场景 | 处理方式 |
|----------|----------|
| 扫描中途磁盘被拔出 / 目录被锁定 | 跳过该目录，标记"扫描失败"，继续扫描其他目录；最终报告中说明 |
| 清理时文件正被占用 | 提示占用进程，用户确认关闭后重试；用户选择跳过则标记"已跳过" |
| 清理时权限不足（非管理员） | 自动触发 UAC 提权请求；用户拒绝提权则该项标记"失败-权限不足" |
| 保险箱写满（5GB 用尽） | 自动淘汰最旧文件腾空间，淘汰前记录日志；若淘汰后仍不足则提示用户手动清理保险箱 |
| 规则库更新失败（网络错误） | 静默使用本地旧规则库，不影响正常使用；设置中提示"规则更新失败，可重试" |
| 系统还原点创建失败 | 弹出提示告知用户原因（如系统未开启还原），询问是否继续清理 |
| 注册表导出备份失败 | 阻止该条注册表清理操作，提示"备份失败，为安全起见已取消本次删除" |
| WinSxS 分析失败（DISM 报错） | 显示具体错误信息，提供"复制错误详情"按钮，建议用户手动运行 DISM 排查 |
| 应用崩溃后恢复 | 下次启动时检测到未完成的清理任务，提示"上次清理未完成，是否查看日志"；保险箱内文件不受影响 |
| 杀软拦截清理操作 | 给出明确提示："某杀软拦截了清理操作，请将本应用加入白名单"，附放行指引链接 |

## 7. 页面/交互简述

### 7.1 信息架构

```
启动页（仪表盘：空间总览 / 可释放预估 / 上次清理收益）
 ├─ 立即扫描 → 扫描进度页 → 结果中心
 │    ├─ 应用缓存清理
 │    ├─ 系统临时与日志
 │    ├─ 组件存储（WinSxS）
 │    ├─ 已卸载残留
 │    ├─ 系统级大文件 / 大文件地图
 │    └─ 注册表健康
 ├─ 清理方案（已保存 / 草稿 / 模板）
 ├─ 保险箱（可恢复列表）
 ├─ 历史与趋势（空间趋势 / 清理收益）
 └─ 设置（规则更新 / 计划任务 / 还原点开关 / 保险箱设置 / 主题 / 关于）
系统托盘：常驻图标 + 右键菜单
```

### 7.2 核心交互闭环

```
点击"立即扫描" → 只读扫描（1-3分钟）→ 分类展示（L1/L2/L3）
→ 用户勾选 + 预估释放量 → 生成清理方案 + DryRun 预演
→ 确认执行？→ 是 → 关闭占用进程 → 保险箱优先移入 → 执行清理
           → 否 → 保存方案草稿，下次继续
→ 结果报告（前后对比 + 明细）→ 写入历史库（可回溯）
```

### 7.3 关键交互细节

- **扫描页**：实时进度条 + 当前扫描目录；扫描中可浏览历史结果。
- **结果页**：每项默认折叠，展开显示"影响与重建方式"。
- **风险徽标**：L1 绿 / L2 黄 / L0 灰，颜色 + 文字双编码（不仅靠颜色区分，适配色弱用户）。
- **L2 确认弹窗**：勾选 L2 项时弹出说明，包含"影响是什么"、"如何恢复"、"删除后会怎样"三要素。
