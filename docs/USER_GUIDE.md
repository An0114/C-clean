## 1. 快速开始

三步走：**装 → 扫 → 清**。

### 1.1 安装

从 [Releases](https://github.com/An0114/C-clean/releases) 下载任一安装包：

| 包 | 适用 |
|---|---|
| `C-DiskCleaner_x.y.z_x64-setup.exe`（NSIS） | 普通用户，双击下一步到底 |
| `C-DiskCleaner_x.y.z_x64_en-US.msi` | 企业批量部署：`msiexec /i 包名.msi /qn` |

**首次运行会被 Windows SmartScreen 拦一下**（因为安装包没有购买代码签名证书）：

1. 看到「Windows 已保护你的电脑」→ 点 **更多信息**；
2. 点 **仍要运行**。

这是正常的，之后不再提示。

### 1.2 第一次扫描

打开应用 → 停在「仪表盘」→ 点 **开始扫描**。等进度条走到 100%（通常十几秒到一分钟，取决于磁盘）。

扫到一半不想等了？点旁边的 **取消扫描**，见 [4.3](#43-取消扫描)。

### 1.3 第一次清理

1. 切到「清理」页，看扫描出来的条目；
2. 建议先点 **预览可清理项**（dry-run）看一眼清单，确认没有你想保留的东西；
3. 勾选要清理的项（或点「**全选 L1（安全）**」一键选安全项），点 **清理已选**。

**被删的文件不会立刻消失**，而是进入「保险箱」，7 天内可以恢复。

> 如果勾选的条目里含有 L2 项，清理前会**弹一次 Windows 授权框（UAC）**——那是在创建系统还原点，属于正常流程，不是报错。详见 [2. 权限与还原点](#2-权限与还原点)。

### 1.4 界面地图

顶栏共八个页签，各有分工：

| 页签 | 做什么 | 会不会删东西 |
|---|---|---|
| **仪表盘** | 开始扫描、看进度、C 盘环形图、30 天趋势、WinSxS 卡片 | 不会 |
| **清理** | 勾选条目执行清理、dry-run 预览、导出报告 | **会**（先进保险箱） |
| **大文件** | 看哪些大文件占空间 | 不会（整页只读） |
| **残留** | 找「注册表与文件对不上」的残留 | 只删「文件残留」，且进保险箱 |
| **注册表** | 启动项 / 卸载残留 / 计划任务体检 | 只删启动项，且先导 `.reg` 备份 |
| **保险箱** | 恢复或永久删除已清理的文件 | **会**（永久删除不可恢复） |
| **历史** | 看所有操作记录与统计 | 不会 |
| **设置** | 规则库、更新、外观、行为偏好 | 不会 |

## 2. 权限与还原点

本版本新增了「需要管理员权限才能做的事」，所以会看到 UAC 弹窗。这一章解释**什么时候弹、为什么要弹、怎么回退**。

### 2.1 什么时候会弹 UAC

| 操作 | 弹几次 | 为什么 |
|---|---|---|
| 扫描 | 不弹 | 只读 |
| 清理（全是 L1 安全项） | 不弹 | 普通权限就能删 |
| 清理（含 L2 项） | **1 次** | 删除前创建系统还原点 |
| WinSxS「分析组件存储」 | **1 次** | DISM 必须管理员权限才能跑 |
| WinSxS「立即清理」 | **2 次** | ① 创建还原点 ② 执行 DISM 清理 |
| 删除注册表启动项 | 不弹 | 改的是当前用户自己的设置 |
| 大文件 / 残留扫描 | 不弹 | 只读 |

弹框里显示的程序名是 **`cclean-elevation.exe`**（描述写着「独立提权 exe（按需 UAC、完成即退出）——只接受固定命令白名单」），**不是主程序 C-Disk Cleaner**——这是刻意的设计，见下。

### 2.2 提权组件是什么

需要管理员权限的操作，交给一个**独立的小程序**去做：

- **按需启动、做完就退**，不会常驻在后台占着管理员权限；
- 只接受**事先写死的几条命令**，不接任何来自界面的自定义参数。也就是说，即使有人想让它执行别的东西，也没有入口——`/ResetBase` 这类危险开关在代码里根本不存在，而不是「传了会被拦下」；
- 弹 UAC 时你看到的是它的名字，不是主程序。**你点「否」也不会出问题**，操作会被取消并给出提示。

### 2.3 还原点怎么看

清理时创建的还原点，名字形如：

```
C-clean cleanup #12 2026-10-31 06:22:00
```

- `#12` 是清理批次号，能对上「哪一次清理」；
- 后面的时间是 **UTC 时间**，比你本地时间可能早或晚几个小时（不是写错了）。

想找它：

1. 开始菜单搜索「**创建还原点**」→ 打开「系统属性 → 系统保护」；
2. 点 **系统还原** 按钮 → 下一步，列表里就能看到那个还原点；
3. 选中它 → 下一步 → 完成，系统会重启并回滚。

也可以直接按 `Win + R` 输入 `rstrui.exe` 回车。

> **注意**：系统还原只回滚系统文件与注册表，**不会把已删除的缓存文件还给你**。要恢复文件请用「保险箱」。还原点的作用是「万一系统出了问题，能退回清理之前的状态」。

**哪里能看到序号**：WinSxS 清理完成的结果条会写「清理前已创建系统还原点 #N」。普通清理页**不显示序号**（还原点是在清理前建的，结果出来时那次操作已经结束），需要确认的话去上面的还原点面板按名字对批次号。

### 2.4 还原点创建失败了怎么办

常见原因：系统还原被关闭、系统保护没给 C 盘分配空间、磁盘空间不足、你在 UAC 框上点了「否」。

此时应用会**停下来问你**：

> 系统还原点创建失败（可能系统还原已关闭）。继续清理将无法回滚，是否继续？

- 点 **取消**：什么都不做，安全；
- 点 **确定**：跳过还原点继续清理，结果里会如实写「本次未创建系统还原点」。

**建议先点取消**，去「系统保护」里把 C 盘的还原打开，再重试一次。缓存文件通常不危险，但留着退路总比没有强。

## 3. 仪表盘

打开应用第一眼看到的就是仪表盘。它只展示信息，不删任何东西。

### 3.1 C 盘环形图

中间的圆环表示 **C 盘已用百分比**，环内是百分比数字，环下是「已用 / 总量」。

- 环的颜色随占用变化：宽裕时是蓝色，超过 85% 转橙，超过 95% 转红；
- 环只统计 **C 盘**（系统盘）。其他盘的空间不在这里。

### 3.2 30 天释放量趋势图

柱状图显示**最近 30 天每天清理释放了多少**。

- **只画有记录的日子**——空白的日子不是「数据丢了」，是那天确实没清理过；
- 鼠标悬停看具体数值；
- 数据来自审计日志，卸载重装应用会一起清空（数据存在数据目录里）。

### 3.3 自动扫描

如果开启了「自动扫描」（设置 → 行为偏好，默认关闭），应用会在后台按你选的间隔（每天 / 每周 / 每月）静默扫描一次：

- **只扫描，不删除**，扫完发一条系统通知告诉你「发现多少可清理」；
- 如果你正在手动扫描，自动扫描会**跳过这一轮**，不会两个扫描撞在一起；
- 应用启动约 1 分钟后做第一次检查，之后每 30 分钟检查一次「到点没有」。

## 4. 扫描

### 4.1 扫描什么

五类目标，各自对应一个脚本：

| 类别 | 典型内容 |
|---|---|
| 浏览器缓存 | Chrome / Edge 等的 Cache、Code Cache、GPUCache |
| 开发工具缓存 | npm / pnpm / yarn / Cargo / pip 等包管理器缓存 |
| 预读取文件 | Windows Prefetch（`.pf` 文件） |
| 系统临时文件 | `%TEMP%`、Windows Temp |
| Windows 更新残留 | `SoftwareDistribution\Download` 等 |

### 4.2 界面

- **进度条**：按脚本分段推进，扫描结束会停在 **100%**（不是 88% 或 96%）。
- **计数**：进度条下方显示已扫描条目数；扫描完成后与「清理」页的总数一致。
- **按钮**：扫描中显示「扫描中…」；完成后变成 **再次扫描**。

### 4.3 取消扫描

扫描中，进度条右侧有 **取消扫描** 按钮。

- 点下去按钮立刻变「**正在停止…**」，这是即时反馈，不代表已经停了；
- 真正的停止发生在**当前脚本跑完、下一个脚本开始之前**——脚本是最小执行单位，不能在中间掐断；
- 所以可能还要等几秒到几十秒（取决于当前脚本剩多少）；
- **已经扫到的结果全部保留**，可以照常去「清理」页勾选清理，不会白扫一趟。

### 4.4 扫描失败怎么办

如果某个脚本执行失败，界面会出现红色错误条。常见原因：

- **PowerShell 执行策略限制**：系统策略禁止运行脚本；
- **权限不足**：个别目录需要管理员权限（应用本身以普通权限运行，这是刻意的安全设计）；
- **杀毒软件拦截**：见 [FAQ](#15-常见问题)。

## 5. 清理

### 5.1 列表与分页

「清理」页按大小从大到小列出扫描结果，**分页显示**（每页固定条数）。翻页时会**清空已勾选项**，避免跨页误删。

### 5.2 风险徽标（L0 ~ L3）

每行都带一个彩色徽标，鼠标悬停能看到这一级的含义：

| 徽标 | 含义 | 能删吗 |
|---|---|---|
| **L0** | 仅提示，不参与清理 | 不参与，勾不上 |
| **L1** | 安全缓存，删了相关程序会自动重建 | 可以直接清 |
| **L2** | 需要你逐项确认（可能是你的数据、也可能需要管理员权限） | 能，但要自己确认 |
| **L3** | 硬编码红线：系统关键路径 | **不能**，勾不上也删不掉 |

看到 `未知风险等级` 的灰徽标不用慌——那说明后端加了新等级而界面还没跟上，程序会保守处理（不让删）。

### 5.3 全选 L1（安全）

列表上方有 **全选 L1（安全）** 按钮，一键勾选**当前页**所有 L1 项，按钮上会写「勾选本页 N 项 L1 安全缓存（约 X MB）」。

- **只勾本页**：跨页全选要先把所有页拉下来，翻页又会清空勾选，两个行为会打架；
- **绝不勾 L2 / L3**：L2 的设计前提就是「逐项确认」，自动全选等于绕过这道设计；
- 本页没有 L1 时按钮是灰的，提示「本页没有 L1 安全项」。

### 5.4 预览（dry-run，强烈建议）

点 **预览可清理项** 会打开只读面板，显示：

- 将被删除的文件数 / 总大小 / 路径清单；
- **会被拦下的条目及原因**（例如命中 L3 红线、路径不在白名单内）。

预览不会删除任何东西。确认后仍走「清理已选」。

### 5.5 执行清理

1. 勾选条目 → 底部显示「已选 N 项，共 X MB」；
2. 点 **清理已选**；
3. 若含 L2 项，此时会弹 UAC 创建还原点（见 [2.1](#21-什么时候会弹-uac)）；
4. 结果条显示「已清理 K 项，释放 X」，以及可能的「M 项已不存在」和「N 项失败」。

**「释放 X」和「磁盘已用」是两回事**，结果条里会同时给：

| 显示 | 含义 |
|---|---|
| 已清理 N 项，释放 X | **删掉的文件大小之和**（本次操作直接处理掉的量） |
| 磁盘已用：清理前 A → 清理后 B | **磁盘真实已用量变化**（查不到时显示「—」） |

两者会有偏差：簇对齐会让实际占用略大于文件大小，清理期间其他程序往盘里写东西又会抵消一部分。所以别指望 A − B 精确等于 X，**报告里两个值都会写出来**，不挑一个糊弄过去。

### 5.6 「已不存在」是什么意思

如果文件在你扫描之后、清理之前被别的程序删掉了，它会被记为 **已不存在**——不算失败，也不计入释放量。这是正常的，不需要处理。

### 5.7 文件被占用怎么办

如果某项清理失败并提示被占用，失败明细里会列出**占用进程**（进程名 + PID）。此时可以：

- 手动关掉那个程序，然后点 **重试**；
- 或点 **关闭占用进程并重试** —— 应用会通过 Windows Restart Manager 关闭占用者再重试。

⚠️ 关闭前会弹确认框，请注意提示：**同一控制台内的相关进程可能一并关闭**（这是 Windows 的限制，不是应用能控制的粒度）。如果占用者是系统保护进程（如 `explorer.exe`），应用会**整批拒绝关闭**，一个都不关。

**「一并关闭」到底是什么意思**：Windows 的重启管理器是按**控制台进程组**关闭的。如果你是在一个 `cmd` 窗口里启动的程序，那个程序锁着文件，那么关闭它时，**同一个 cmd 窗口里的相关进程也可能一起退出**。实测（两个共用控制台的 PowerShell 进程，只对其中一个的文件请求关闭，另一个也退出了）确实如此。

这个粒度应用无法收窄——要么整组关，要么不关。所以：**关闭前请先保存其它窗口里的工作**。如果不想承担这个风险，就手动关掉占用程序，再点「重试」。

### 5.8 自动重启被关闭的进程（默认关闭）

在「设置 → 行为偏好」里可以开启「自动重启被关闭的进程」。开启后，清理时被关掉的程序会在清理完成后自动拉起，省去手动重开。

**默认关闭**，因为不是所有程序都适合被自动拉起。想精细控制见 [12.4 行为偏好](#124-行为偏好)。

### 5.9 导出报告

清理完成后，结果条上有两个按钮：

| 按钮 | 产出 | 适合 |
|---|---|---|
| **导出 HTML 报告** | 单个 `.html` 文件，双击用浏览器打开 | 自己存档、发给别人看 |
| **导出 CSV** | `.csv` 明细表（每个文件一行：路径 / 大小 / 状态 / 原因） | 用 Excel 统计 |

**保存在哪**：数据目录下的 `reports\` 文件夹，文件名形如 `cleanup-report-1761888000.html`（那串数字是时间戳）。导出成功后界面会显示**完整路径**，复制到资源管理器即可打开。

**CSV 用 Excel 打开不会乱码**：文件带 UTF-8 BOM 头，中文路径正常显示。如果用记事本打开看到 `路径,大小(字节),状态,原因` 前面有几个怪字符，那是 BOM，属正常。

**HTML 报告里有什么**：生成时间、盘符、清理前后已用空间对比、成功 / 失败 / 已不存在的条目明细。文件名会做 HTML 转义，不用担心文件名里的特殊字符破坏页面。

## 6. 保险箱

清理的文件先放这里，**7 天内可恢复**。这是本工具与「一键全清」工具最大的区别。

### 6.1 列表信息

每行显示：原路径 / 大小 / 移入时间 / **来源** / 操作。

- **来源**：显示清理批次号（如 `#12`），能对上是哪一次清理删的。早期版本（v0.1.6 之前）入箱的条目没有记录来源，显示「历史（无来源）」——这不是故障，是当时确实没存。
- **大小**：目录类条目显示的是**整个目录的合计大小**（递归求和），不是目录本身占的几个字节。

### 6.2 筛选

| 筛选 | 说明 |
|---|---|
| 时间 | 全部 / 24 小时 / 3 天 / 7 天 |
| Session | 多选，按清理批次筛；未选 = 全部 |

### 6.3 恢复

勾选条目 → 点 **恢复**。文件回到**原路径**。

- 原父目录不存在时会**自动创建**多层目录；
- 如果原路径已经被别的文件占用，会拒绝恢复并提示——先处理掉那个文件再试；
- 恢复后该条目不再出现在列表里（但记录保留在数据库中，用于追溯「什么时候恢复的」）。

### 6.4 永久删除

勾选条目 → 点 **永久删除** → 确认。

⚠️ **此操作不可恢复**。确认框会明确提示。永久删除是为了在确认不需要之后释放保险箱空间（保险箱总容量上限 5 GB，超出会按时间先入先出淘汰）。

### 6.5 7 天自动清理（purge）

超过保留期的条目会被**自动永久删除**，不需要你手动点。规则：

- **什么时候跑**：应用启动时补一次，运行期间定期检查；不是靠 Windows 计划任务，所以**应用没开着的时候不会删**（下次打开会补上）；
- **会留痕**：每一条自动删除都写进审计日志（事件类型 `auto_purge`），历史页能查到；
- **文件删不掉怎么办**：比如文件正被占用，此时**数据库记录会保留**，下一轮再试。不会出现「记录没了但文件还在」的孤儿；
- **文件已经不在了**：直接清掉记录，这是正常的（你可能自己手动删过）。

保险箱页顶部有一行提示说明保留策略，看到它就知道这个机制在生效。

### 6.6 跨盘行为（保险箱与文件不在同一个盘）

先说结论：**移入支持跨盘，恢复不支持**。两者不对称，原因见下。

**移入（清理时进保险箱）——支持跨盘**：

- 同盘时是一次 `rename`，瞬时完成，不占额外空间；
- 跨盘时 `rename` 会被系统拒绝（不允许跨卷移动），应用自动改为「**复制到保险箱 → 删除源文件**」；
- 所以跨盘移入**比同盘慢**（要完整复制一遍文件），文件越大越明显；
- 如果复制成功但删除源文件失败（文件被占用等），应用会**删掉刚复制的那份**再报错，避免保险箱里留一个和源文件重复的副本。

**恢复（从保险箱拿回原位置）——不支持跨盘**：

- 若保险箱与原路径不在同一个盘，恢复会**直接失败**并提示 IO 错误；
- 失败时**文件仍在保险箱里**（不会丢），原位置也不会留下半个文件；
- 处理办法见 [FAQ Q9](#q9跨盘恢复报错怎么办)。**不建议**手动去 `%APPDATA%` 里翻保险箱文件——那个目录有数据库索引，手动搬动会让索引对不上。

**为什么恢复没做跨盘回退**：照搬「复制 + 删除」会引入一个新的失败模式——复制成功、删除保险箱里那份失败，结果两处都有同一个文件，用户不知道该信哪个。这个需要单独设计（比如先标记状态再删），一直没做。当前行为已由自动化测试固化（`cross_disk_restore_currently_returns_io_error`），避免以后误以为支持。

**实际影响很小**：保险箱固定放在 `%APPDATA%\com.and0114.cclean`（C 盘），而清理目标绝大多数也在 C 盘。只有「把数据目录改到 D 盘，再从 C 盘删了文件」这种组合才会碰到。

## 7. WinSxS 组件存储

「WinSxS」是 Windows 存放组件（系统文件各版本副本）的目录。装更新、装功能时旧版本会留在里面，时间久了能占几个 GB。

### 7.1 开始之前

- 这个操作**必须管理员权限**，会弹 UAC；
- **会先创建系统还原点**，再动手清理；
- **不能撤销**：清理会删掉旧版本组件，之后无法卸载已安装的更新（这也是本工具**不提供 `/ResetBase`** 的原因——那个开关会把「无法卸载更新」变成「永久无法卸载」，代价太大，我们连入口都不做）；
- 分析通常十几秒到几分钟，机械硬盘更久。**期间请勿关闭窗口**。

### 7.2 分析

仪表盘 →「WinSxS 组件存储」卡片 → 点 **分析组件存储** → UAC 点「是」。

> 卡片**不会自动分析**：一进页面就弹 UAC 是打扰行为，必须你自己点。

分析完成后会显示：

| 字段 | 含义 |
|---|---|
| **可清理** | DISM 认为可以回收的空间 |
| **可回收包** | 可以清掉的旧版本组件包数量 |
| **组件存储实际大小** | WinSxS 目录当前占用 |
| **上次清理** | 系统记录的上次清理日期，可能是「从未清理」 |
| **DISM 建议** | 「建议清理」或「暂不建议清理」 |

「暂不建议清理」通常意味着没什么可回收的，此时「立即清理」按钮是禁用的，下面会写「当前没有可回收的组件，无需清理」。

### 7.3 清理

点 **立即清理** → 确认框会告诉你大概能清多少 → 确定 → **UAC 弹两次**（第一次建还原点，第二次跑 DISM）。

清理过程中卡片下方会出现一个等宽字体的黑框，**实时滚动 DISM 的输出**（只显示最近 8 行）。看到它在动就说明在干活，别关窗口。

完成后结果条会写：

- 「组件存储清理完成」或「清理失败（DISM 退出码 N）」；
- 「清理前已创建系统还原点 #N」或「本次未创建系统还原点」；
- 共处理了多少行 DISM 输出；
- 失败时附上输出尾部——DISM 的失败原因几乎总在最后几行。

点 **重新分析** 可以看到清理后的最新数字。

### 7.4 注意事项

- **15 分钟上限**：DISM 跑超过 15 分钟会被强制中止并报错。机械硬盘 + 组件存储特别大的机器可能碰到。碰到就分几次做，或改用系统自带的「磁盘清理」。
- **系统还原关闭时会问你要不要继续**：见 [2.4](#24-还原点创建失败了怎么办)。
- **清理完 C 盘空间不会立刻变大**：组件清理释放的空间有时要等系统完成内部整理，或者重启后才体现。

## 8. 大文件地图

「大文件」页回答一个问题：**我的 C 盘被什么占着？**

### 8.1 四个分类

| 分类 | 是什么 | 建议 |
|---|---|---|
| **休眠文件** | `hiberfil.sys`，休眠时把内存写到盘上用的，大小≈内存容量 | 不用休眠可关闭：管理员命令行执行 `powercfg /h off`（会同时关掉快速启动） |
| **旧系统备份** | `Windows.old`，升级系统时留下的旧系统 | 用「磁盘清理 → 清理系统文件」删，不要手删 |
| **回收站** | `$Recycle.Bin` 里所有用户删掉但没清空的东西 | 打开回收站确认无需恢复后右键「清空回收站」 |
| **Top 100 大文件** | 系统盘上占用空间最大的文件 | 逐个看，确认不需要再自己处理 |

进页面会自动扫一次（本页纯只读，不会打扰你）。想刷新点 **重新扫描**。

### 8.2 为什么这一页不能删

**整页只有「重新扫描」一个按钮，没有任何删除入口。** 这是刻意的：

上面四类的正规处理方式**各不相同**——休眠文件要用 `powercfg` 关、旧系统要用系统自带的磁盘清理、回收站要清空、大文件要你自己判断。给一个统一的「删除」按钮，等于把「该怎么做」这个判断责任推给一个猜的算法，出了事没人能负责。

所以这一页的定位是**诊断**，不是执行。看清了，用各自正确的方式处理。

### 8.3 「已达扫描上限」是什么意思

页面顶部可能出现橙色提示：**已达扫描上限，Top 列表可能不完整**。

原因是扫描有「20 万个条目 / 20 秒」双上限——宁可少列几条，也不让一次点击变成转圈几分钟。文件特别多的机器一定会撞到这个上限。

这不影响上面三张分类卡片的数字（它们各自独立统计），只影响 Top 100 列表的完整性。

## 9. 残留扫描

「残留」页回答另一个问题：**有哪些东西是「注册表说装了、盘上却没有」或者「盘上有、注册表里却没有」？**

### 9.1 两类结果

页面上方两个 tab，各带数量：

| tab | 判定依据 | 置信度 | 能处理吗 |
|---|---|---|---|
| **文件残留** | 安装目录还在，但注册表卸载列表里找不到归属 | 低 | 可以移入保险箱 |
| **注册表残留** | 注册表记着安装目录，但那个目录已经不存在 | 高 | **不能**，只提示 |

### 9.2 怎么看这个列表

每行四列：**名称 / 路径 / 大小 / 类型**，外加两个徽标：

- **置信度**：绿色「高」= 证据明确；橙色「低」= 只是「没找到对应项」，可能是误报；
- **风险**：文件残留一律标 L2（需你确认）。

顶部还有一行统计：读了多少个卸载项、扫了多少个安装目录、耗时多少。

### 9.3 文件残留：移入保险箱

1. 勾选要处理的项（**默认一个都不勾，也没有「全选」按钮**）；
2. 点 **移入保险箱（N 项）**；
3. 确认框会列出前 5 条路径与总数；
4. 确定后，目录被**整体移入保险箱**（内部结构完整保留），7 天内可在保险箱页恢复。

> 为什么默认不勾、也不给全选？因为「注册表里没有」推不出「已卸载」。**全选按钮等于鼓励批量误删**，所以只给逐项勾选。

**如果提示「勾选里有受保护目录」**：说明命中了安全红线（桌面、文档、浏览器数据、系统目录等），这些**任何情况下都不动**。把那条去掉再试。

**如果部分失败**：结果里会同时显示成功数与逐条失败原因，不会整批报错——那样会让人以为全挂了。

### 9.4 注册表残留：为什么不能代删

这个 tab **没有勾选框，也没有删除按钮**，只列出注册表键路径和处理建议。

原因很直接：**改错一个注册表键，可能让某个程序甚至系统起不来**。而且「目录不存在」也可能只是你把程序装到了移动硬盘上、或者临时拔了盘。

想清理的话，正规做法是：

1. 打开「设置 → 应用 → 已安装的应用」，找到对应程序，点「卸载」或「修改」→「修复」；
2. 找不到的话，用 `regedit` 手动删对应的 `Uninstall` 子键（路径在列表里给了）。

### 9.5 列表里有我正常使用的程序？

这是**已知局限**，不是 bug。绿色软件、便携版、部分微软商店应用**本来就不写卸载项**，所以一定落进「文件残留」。

四重措施兜底：低置信徽标 + 默认不勾选 + 不提供全选 + 移入保险箱可恢复。**看到认识的程序，直接跳过就好。**

## 10. 注册表健康中心

「注册表」页做三件事：看开机启动项、看卸载残留、看计划任务。

### 10.1 三个 tab

| tab | 内容 | 能删吗 |
|---|---|---|
| **启动项** | 注册表 `Run` 键里的开机自启项（三个位置：当前用户 + 本机 64 位 + 本机 32 位） | 能，且**删前自动备份** |
| **卸载残留** | 与「残留」页的类型 A 相同（注册表记着目录但目录没了） | 不能 |
| **计划任务** | `System32\Tasks` 里的计划任务及其命令 | 不能 |

每行显示：名称 / 命令或路径 / 风险 / 建议。

### 10.2 启动项：删除与备份

只有**启动项** tab 有勾选框，而且**不是每行都有**：

- 风险 **L2**（第三方启动项、或目标文件已不存在）：有勾选框，可以删；
- 风险 **L3**（命令在 `C:\Windows` 下、或命中安全软件关键词如火绒 / 360 / Defender 等）：**没有勾选框**，只显示「L3 禁删」。

删的流程：勾选 → 点 **删除并备份** → 确认框列出所有值名 → 确定。

**删前会自动导出 `.reg` 备份**。备份写不出来就**不删**（宁可失败也不留无法回退的操作）。界面会显示备份文件的完整路径。

> 后端会**再独立复核一次**风险等级，不信界面传来的值——所以即使有人改了界面，也删不掉系统启动项。

### 10.3 备份怎么恢复

备份文件在数据目录的 `registry_backups\` 下，文件名形如 `HKCU-Software-Microsoft-Windows-CurrentVersion-Run-1761888000.reg`。

恢复方法：**双击那个 `.reg` 文件** → Windows 问「是否确认添加」→ 是。

因为备份是**整个键**导出的（`.reg` 格式本身不支持只导一个值），所以导入会把那个键下**所有**启动项恢复成备份时的状态。如果你在那之后又加过新启动项，它们会被覆盖掉——恢复前留意一下。

### 10.4 计划任务：需要管理员权限

`C:\Windows\System32\Tasks` 默认只有管理员能读。所以普通权限下打开这一页，你会看到：

> 需要管理员权限（System32\Tasks 默认只有管理员可读）

**这不是「没有计划任务」**，是「看不到」。界面刻意把这两种情况分开显示——把「读不到」说成「没有」等于骗人。

想看计划任务，用系统自带的「任务计划程序」（开始菜单搜 `taskschd.msc`），以管理员身份运行。

## 11. 历史与审计

「历史」页展示两类信息：

- **统计卡片**（仪表盘）：总释放空间 / 成功次数 / 失败次数 / 清理轮次；
- **清理历史**（历史页）：每条记录的时间 / 事件类型 / 路径 / 详情 / 结果。

事件类型包括扫描、清理、移入保险箱、恢复、永久删除、**自动过期清理（`auto_purge`）**、创建还原点等。**每一次删除决定都有记录**，出问题可以回溯到具体哪一次、哪个文件。

## 12. 设置

「设置」页分四块：规则库、应用更新、外观、行为偏好。

### 12.1 规则库

规则库决定「哪些路径算可清理」。应用会定期检查远端是否有新版本：

| 按钮 | 作用 |
|---|---|
| **检查更新** | 拉取远端版本号与 checksum 对比 |
| **应用更新** | 下载并应用新规则（旧版自动备份为 `.bak`） |
| **回滚到上一版** | 仅在存在备份时出现，用于规则出问题时退回 |

状态可能是三种之一：**有新版本** / **已是最新** / **离线模式**（网络不可用时自动用本地规则，功能不受影响）。

### 12.2 应用更新

显示当前版本与是否有新版本。点 **检查应用更新** 会显示「当前 vX / 发现 vY」。

### 12.3 外观（主题）

三选一：

| 选项 | 效果 |
|---|---|
| **跟随系统**（默认） | 系统切深色它就深色，系统切浅色它就浅色 |
| **浅色** | 固定浅色 |
| **深色** | 固定深色 |

切换**即时生效**，不用重启。选择会存进本地数据库，下次打开还是这个。

> 深色模式目前还没覆盖所有页面——「清理」「保险箱」「历史」三页有部分元素颜色是写死的，深色下个别文字对比度偏低。这是已知问题，后续版本补齐。

### 12.4 行为偏好

**自动重启被关闭的进程**（默认关闭）：见 [5.8](#58-自动重启被关闭的进程默认关闭)。

**重启白名单**（每行一个进程名，支持 `*` 通配，如 `*.exe`）：

- **留空 = 不限制**：所有可重启的进程都会被拉起；
- **填了内容 = 只允许这些**：注意实际语义是「**只有被关闭的可重启进程全部在名单内才会重启**」。

为什么是这个语义？因为 Windows 的重启接口**一次只能重启整批、无法逐个挑选**。所以只要有一个被关闭的进程不在名单内，应用就整批跳过——否则一重启就会把您明确排除的进程也拉起来。

填完点 **保存白名单** 生效，重启应用后依然保留。

**自动扫描**（默认关闭）：开启后按「每天 / 每周 / 每月」在后台静默扫描，**只扫描不删除**，完成后发系统通知。详见 [3.3](#33-自动扫描)。

## 13. 托盘与开机自启

### 13.1 关闭窗口 ≠ 退出程序

点窗口右上角的 **×**，程序**不会退出**，而是**隐藏到系统托盘**继续在后台待着（这样自动扫描、通知才能正常工作）。

**真正退出**：右键点托盘图标 → **退出**。

> 如果你习惯「关窗即退出」，这个变化可能会让你以为程序卡住了——去右下角托盘区（可能要展开「显示隐藏的图标」）找一下它就在那儿。

### 13.2 托盘右键菜单

| 菜单项 | 作用 |
|---|---|
| **立即扫描** | 不等窗口，直接开始一次扫描（结果在窗口里看） |
| **打开主窗口** | 把隐藏的窗口叫回来（左键双击托盘图标也行） |
| **退出** | 真正结束程序 |

### 13.3 开机自启

在设置页开启「开机自启」后，登录 Windows 时应用会自动启动并缩到托盘。

- 开关状态**以系统注册表为准**，不是另存一份配置——所以在「任务管理器 → 启动」里禁用，应用里也会同步显示为关闭，不会出现「应用说开着、系统其实关了」；
- 卸载时系统会自动清理这条启动项，不留残渣。

## 14. 更新机制

### 14.1 自动检查

应用启动时会**静默检查**一次新版本（不阻塞、不弹窗）。发现新版本时，顶部出现蓝色 banner：

```
发现新版本 v0.2.1        [立即更新]  [稍后]
```

点 **稍后** 会记住这个版本，下次启动不再打扰（但更高版本出现时会再次提示）。想手动看，去「设置 → 应用更新」。

### 14.2 下载与安装

点 **立即更新** 后 banner 显示：

- 进度条 + 百分比；
- 已下载 / 总大小；
- 实时速度（约 1 秒刷新一次，做了平滑处理所以不会剧烈跳动）。

下载完成会显示「安装中，即将重启…」，随后自动拉起安装程序并重启到新版本。

> 如果服务器没有提供文件总大小，会退化成只显示「已下载 X.X MB（总大小未知）」，这是正常降级。

### 14.3 更新失败

失败时 banner 变红并给出中文原因：

| 提示 | 含义 | 怎么办 |
|---|---|---|
| 网络连接失败，请检查网络后重试 | 下载/请求失败 | 检查网络，点 **重试** |
| 签名校验失败，更新包可能已损坏，请重新下载 | 更新包被篡改或不完整 | 点 **重试**；反复失败请从 Releases 手动下载 |
| 磁盘空间不足，请清理 C 盘后重试 | 下载目录空间不够 | 清理后重试 |
| 当前已是最新版本 | 检查时发现没有更新 | 无需处理 |

失败 banner 提供 **重试** 与 **关闭** 两个按钮。

## 15. 常见问题

### Q1：安装时 Windows 说「已保护你的电脑」，是病毒吗？

不是。这是 SmartScreen 对**未做代码签名**程序的默认拦截。点「更多信息 → 仍要运行」即可。

为什么不做签名、什么条件下会做，见 [`docs/research/code-signing-evaluation.md`](research/code-signing-evaluation.md)。

### Q2：杀毒软件报毒 / 拦截怎么办？

清理工具的行为（批量删除临时文件、通过 Restart Manager 关闭进程、调用 DISM）与某些恶意软件特征重合，容易触发启发式检测。建议：

1. 把安装目录加入杀软信任区；
2. 如果方便，把误报信息提交给杀软厂商（附上 GitHub 链接，开源项目通常会被加白）。

### Q3：清理后文件去哪了？

在**保险箱**里，7 天内可恢复。只有你在保险箱里点「永久删除」、或者 7 天到期自动清理，才会真正消失。

### Q4：为什么某些文件清不掉？

常见原因：

- **被占用**：见 [5.7](#57-文件被占用怎么办)；
- **命中 L3 红线**：系统关键路径被硬编码禁止删除，这是安全设计，无法绕过；
- **权限不足**：需要管理员权限的目录，应用不会为了删缓存就去提权（最小权限原则）。

### Q5：会不会误删我需要的东西？

四道防线：① dry-run 预览让你先看清单；② L3 红线硬编码禁止系统关键路径；③ 保险箱 7 天可恢复；④ 不可逆操作前建还原点、删注册表前导备份。

即便如此，**第一次使用建议先 dry-run 看一眼**，确认规则符合你的环境（比如某些开发缓存你可能想保留）。

### Q6：数据会上传吗？

不会。全本地处理，无遥测、无云上传、无广告 SDK。唯一的网络请求是「规则库更新」和「版本检查」，两者失败都不影响清理功能。

### Q7：设置页第一次打开时控制台有红色报错？

这是已知问题（G6）：首次调用会尝试一个较快的 IPC 通道，失败后自动回退到备用通道，**功能完全正常**，同一窗口内再次进入设置页不再出现。属底层框架（Tauri 2）的已知行为，不影响使用。

### Q8：卸载后我的数据还在吗？

在。数据存放在 `%APPDATA%\com.and0114.cclean`，卸载程序**不会**删除它（避免误删你的保险箱文件）。如需彻底清理，手动删除该目录。

### Q9：跨盘恢复报错怎么办？

现象：点「恢复」后提示 IO 错误，文件没回到原位置。

原因：保险箱与文件原位置**不在同一个盘**，而恢复只支持同盘移动（移入支持跨盘，恢复不支持，详见 [6.6](#66-跨盘行为保险箱与文件不在同一个盘)）。

怎么办（按推荐顺序）：

1. **等文件过期前手动处理**：保险箱保留 7 天，在这期间你有充足时间。先确认文件内容是否真的还需要——多数情况下清理掉的都是缓存。
2. **把数据目录改回与原文件同盘**：如果你之前把数据目录设到了别的盘（`%APPDATA%` 被重定向等），改回去后重新打开应用，恢复就能成功。
3. **实在要救**：在应用**关闭**的情况下，从 `%APPDATA%\com.and0114.cclean\SafeBox\` 找到对应文件复制出来，再重启应用并把该条目标记为已处理。注意：这一步会让人工操作与数据库索引不一致，**只在文件确实重要时做**。

### Q10：为什么清理时会弹 UAC？

因为你勾选的条目里含有 L2 项，应用要在删除前**创建系统还原点**。这是本版本新增的安全措施，不是报错。不想弹窗就只清 L1（用「全选 L1（安全）」）。详见 [2. 权限与还原点](#2-权限与还原点)。

### Q11：点了 × 窗口关了但程序还在？

这是设计如此——关闭窗口只是**隐藏到托盘**，程序继续在后台跑（自动扫描靠它）。想彻底退出：右键托盘图标 → **退出**。详见 [13. 托盘与开机自启](#13-托盘与开机自启)。

### Q12：大文件页为什么不能删文件？

因为那四类（休眠文件 / 旧系统备份 / 回收站 / 大文件）的正规处理方式各不相同，统一代删一定会出事。这一页的定位是**诊断**：看清了，用各自正确的方式处理。详见 [8.2](#82-为什么这一页不能删)。

### Q13：残留列表把我正在用的程序报成残留了？

已知局限。绿色软件、便携版、部分商店应用本来就不写卸载项，所以会被判成「文件残留」。四重措施兜底（低置信徽标 + 默认不勾 + 无全选 + 移入保险箱），**看到认识的程序跳过就行**。详见 [9.5](#95-列表里有我正常使用的程序)。

### Q14：WinSxS 清理完 C 盘没变大？

组件清理释放的空间有时要等系统完成内部整理、或者重启后才体现。另外「可清理」是 DISM 的估算值，实际能回收多少取决于系统状态。点「重新分析」看最新数字。
